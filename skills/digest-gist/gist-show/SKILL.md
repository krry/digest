# GIST Show

If the repo was just cloned or local datastore files are missing, run:

```bash
~/gist/bin/init.sh
```

Then run the script and display its output verbatim:

```bash
~/gist/bin/show.sh [all]
```

Pass `all` if Chef asked to see archived items.
